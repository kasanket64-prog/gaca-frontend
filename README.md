# GACA Frontend — Repository Scaffold

This repository currently contains only a minimal README. It is reserved for the frontend of a device-telemetry / activity-monitoring project; **no application implementation or working UI is present on the default branch**.

## Related work

The companion [GACA backend](https://github.com/kasanket64-prog/gaca-backend) exposes prototype endpoints for submitting device data and retrieving recent records.

## Proposed frontend scope

A future implementation could include a device selector, live or historical telemetry table, clear sensor-permission notices, and authenticated dashboard navigation. These are **design directions, not completed features**.

## Before implementation

Define the user roles, consent requirements and data retention rules. Do not connect real face or voice telemetry to a public demo without authentication and a privacy review.
